## 🎯 **COMO USAR O SISTEMA ADMINISTRATIVO**

### **Iniciar o Sistema**

```bash
cd /mnt/c/Projetos/dfe-sync
./start-sistema-admin.sh
```

### **Acessar a Interface**

- 🌐 **Sistema Administrativo**: http://localhost:5173
- 🔗 **API Docs**: http://localhost:8001/docs

### **Parar o Sistema**

- Pressione `Ctrl+C` no terminal
- Ou use: `./stop-sistema.sh`

## 🔄 **WORKFLOWS COMPLETOS SEM LINHA DE COMANDO**

### **1. Cadastrar Nova Empresa**

1. 🏢 Acesse **Empresas** → **Nova Empresa**
2. 📝 Preencha CNPJ, razão social, dados
3. ✅ Configure se é monitorada
4. 💾 Salve com um clique

### **2. Importar Documentos**

1. 📁 Acesse **Importação**
2. 🖱️ Arraste arquivos ou selecione pasta
3. ⏳ Acompanhe progresso em tempo real
4. ✅ Veja resultados detalhados

### **3. Classificar XMLs Pendentes**

1. 🔄 Acesse **Classificação**
2. 👁️ Visualize XMLs não classificados
3. ☑️ Selecione múltiplos documentos
4. 🏷️ Aplique classificação em lote

### **4. Gerenciar Certificados**

1. 🔐 Acesse **Certificados**
2. 📤 Faça upload do arquivo .pfx
3. 🔒 Configure senha e validade
4. ⚠️ Monitore vencimentos
