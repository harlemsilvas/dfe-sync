# Sistema de Gerenciamento DFE Sync - Web Admin

Criando um sistema web completo para gerenciar todo o sistema DFE Sync sem usar linha de comando.

## Funcionalidades Implementadas

### 1. Menu Principal
- Dashboard
- Cadastros
- Importação
- Classificação 
- Relatórios
- Configurações

### 2. Módulos de Cadastro
- Empresas (CRUD completo)
- Certificados (gestão e validação)
- Empresas não monitoradas
- CFOPs e operações fiscais
- Usuários e permissões

### 3. Importação e Classificação
- Localizador de pastas XML
- Upload de arquivos
- Validação de documentos
- Classificação manual
- Visualizador de XMLs

### 4. Relatórios e Logs
- Dashboard com métricas
- Logs do sistema
- Relatórios de importação
- Estatísticas de classificação

### 5. Configurações
- Parâmetros do sistema
- Regras de classificação
- Backup e restore
- Manutenção
